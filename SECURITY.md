# Security policy

## Supported versions

Security fixes target the latest version available from
[GitHub Releases](https://github.com/Ma1kovich/chiu/releases).

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, sensitive exploit details, secrets,
personal information, or sensitive diagnostics in an ordinary GitHub issue or
other repository-visible discussion.

Use [GitHub private vulnerability reporting](https://github.com/Ma1kovich/chiu/security/advisories/new).
Do not include vulnerability details or sensitive material in any public issue.
